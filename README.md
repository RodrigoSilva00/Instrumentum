# 🎹 INSTRUMENTUM

**Explore o universo dos instrumentos musicais!**

O INSTRUMENTUM é um projeto desenvolvido para apresentar diferentes instrumentos musicais de forma interativa e visual. A proposta é proporcionar uma experiência simples e agradável, permitindo conhecer características, funcionamento e curiosidades sobre cada instrumento.

## ✨ Funcionalidades

- **Galeria de instrumentos:** apresentação de diferentes instrumentos musicais.
- **Detalhes interativos:** ao selecionar um instrumento, é possível visualizar informações sobre suas características e funcionamento.
- **Piano interativo:** teclado musical diretamente na página, permitindo tocar notas pelo mouse, toque na tela ou teclado do computador.
- **Modo claro e escuro:** alternância entre temas visuais.
- **Seção Sobre Mim:** espaço dedicado à apresentação do desenvolvedor.
- **Design responsivo:** adaptação da interface para diferentes tamanhos de tela.

## 🎼 Instrumentos apresentados

- Piano
- Violão

- Ukulele
- Cavaquinho
- Gaita
- Pandeiro
- Ganzá

## 🛠️ Tecnologias utilizadas

- **HTML** — estrutura do projeto.
- **CSS** — estilização e aparência.
- **JavaScript** — interatividade e funcionalidades.

## 🚀 Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão **Live Server** no Visual Studio Code para visualizar as alterações em tempo real.
